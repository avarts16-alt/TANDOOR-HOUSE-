Backup & restore

Entries are stored on this browser/device. They do not automatically sync between phones. Export a backup regularly.

Cloud backup is not connected in this version. To sync across devices safely, a database and authentication must be configured; do not put passwords or API keys in a public GitHub repository.

Using the app

1. Record each sale and expense daily.

2. Track stock additions and stock used/wasted.

3. At closing, enter actual cash counted.

4. Record staff advances, payments and unpaid salary.

5. Export backups weekly and before changing phones.
